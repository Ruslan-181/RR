## Завдання № 1

**Файл:** `task1.c`

### Умова
Не використовуючи стандартні математичні функції (без підключення бібліотеки `<math.h>`), розрахувати суму ряду, де N — ціле число, що вводиться з клавіатури:

<img width="125" height="58" alt="image" src="https://github.com/user-attachments/assets/1d862c52-01ca-4d30-9113-451a72e521b1" />


### Прототип функції
```c
/**
 * @brief Розраховує суму заданого ряду від n = 1 до N.
 *
 * Формула ряду: S = sum(2/n + n/2).
 * Оскільки результатом ділення можуть бути дробові числа,
 * розрахунок ведеться у типі double.
 *
 * @param limit Верхня межа ряду (ціле число N, N >= 1).
 * @return Сума ряду у вигляді дійсного числа подвійної точності.
 */
double calculateSeriesSum(int limit);
```

### Пояснення реалізації

* **Оголошення змінних та контроль введення:** у функції `main()` цикл `while (1)` перевіряє, щоб користувач ввів саме ціле число (`readStatus == 1`) та дотримався умови `limitN >= 1`. У разі введення літер або некоректних символів буфер очищається через `scanf("%*[^\n]")`, що запобігає зацикленню.

```c
    SetConsoleOutputCP(CP_UTF8);

    int limitN;
    int readStatus;

    while (1) {
        printf("Введіть ціле число N (N >= 1): ");
        readStatus = scanf("%d", &limitN);

        if (readStatus == EOF) {
            return 1;
        }
        if (readStatus != 1) {
            printf("Помилка: некоректне введення. Будь ласка, введіть ціле число.\n");
            scanf("%*[^\n]");
            continue;
        }
        if (limitN < 1) {
            printf("Помилка: значення N має бути більше або дорівнювати 1. Спробуйте ще раз.\n");
            continue;
        }
        break;
    }
```

* **Розрахунок суми ряду без математичних функцій:** обчислення винесено в окрему функцію `calculateSeriesSum()`. Щоб уникнути цілочисельного ділення (наприклад, `2 / 3 == 0`), у виразі використано дробовий літерал `2.0`.

```c
double calculateSeriesSum(int limit) {
    double totalSum = 0.0;

    for (int n = 1; n <= limit; n++) {
        double term = (2.0 / n) + (n / 2.0);
        totalSum += term;
    }

    return totalSum;
}
```

* **Виведення результату:**

```c
    double resultSum = calculateSeriesSum(limitN);
    printf("\nСума ряду S = %lf\n", resultSum);
```

## Завдання № 2

**Файл:** `task2.c`

### Умова
Написати програму, яка знаходить значення, що найчастіше зустрічається в одномірному статичному масиві типу `int` (розмір `ARRAY_SIZE = 7`). Значення елементів вводяться з клавіатури з перевіркою належності діапазону `[-3; 3]` та можливістю повторного введення при помилці. Алгоритм пошуку реалізувати в окремій функції.

### Прототип функції
```c
/**
 * @brief Знаходить значення, що найчастіше зустрічається в одновимірному масиві.
 *
 * Якщо кілька різних чисел мають однакову максимальну кількість повторень,
 * повертається перше з них у порядку слідування в масиві.
 *
 * @param numbers Константний одновимірний масив цілих чисел (без права модифікації).
 * @param size Кількість елементів у масиві.
 * @return Значення, що зустрічається найчастіше, або 0, якщо розмір масиву <= 0.
 */
int findMostFrequent(const int numbers[], int size);
```

### Пояснення реалізації

* **Головна функція `main()` та валідація в одному циклі:** заповнення статичного масиву `numbers` реалізовано в одному циклі `for`, де лічильник `i` збільшується лише після успішної перевірки типу даних та діапазону `[-3; 3]`.

```c
int main(void) {
    SetConsoleOutputCP(CP_UTF8);

    int numbers[ARRAY_SIZE];
    int inputNumber;
    int readStatus;

    for (int i = 0; i < ARRAY_SIZE;) {
        printf("%d: Введіть ціле число з проміжку [-3; 3]: ", i + 1);
        readStatus = scanf("%d", &inputNumber);

        if (readStatus != 1) {
            printf("Помилка: введіть ціле число.\n");
            scanf("%*[^\n]");
            continue;
        }

        if (inputNumber < -3 || inputNumber > 3) {
            printf("Значення виходить за межі [-3; 3]. Спробуйте ще раз.\n");
            continue;
        }

        numbers[i] = inputNumber;
        i++;
    }

    int mostFrequentValue = findMostFrequent(numbers, ARRAY_SIZE);
    printf("\nЗначення, що найчастіше зустрічається: %d\n", mostFrequentValue);

    return 0;
}
```

* **Алгоритм пошуку найчастішого елемента:** функція `findMostFrequent()` перебирає кожен елемент масиву та у вкладеному циклі підраховує кількість його повторень, оновлюючи поточного лідера.

```c
int findMostFrequent(const int numbers[], int size) {
    if (size <= 0) {
        return 0;
    }

    int mostFrequent = numbers[0];
    int maxCount = 0;

    for (int i = 0; i < size; i++) {
        int currentCount = 0;

        for (int j = 0; j < size; j++) {
            if (numbers[j] == numbers[i]) {
                currentCount++;
            }
        }

        if (currentCount > maxCount) {
            maxCount = currentCount;
            mostFrequent = numbers[i];
        }
    }

    return mostFrequent;
}
```
